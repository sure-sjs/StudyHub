# StudyHub · 个人学习导航

一个把日常学习和生活中常用的网站集中到一处的个人导航工作台。纯静态、零依赖，直接打开 `index.html` 即可使用（推荐本地 HTTP 服务），也可以原样部署到 GitHub Pages。

> 当前版本：**V0.1.1**（网站管理）

## 功能

- **六个固定视图**：全部网站 / 课程学习 / 编程开发 / 专业学习 / 文献资料 / 校园生活，点击即筛选，点「全部网站」恢复全部。左侧「我的收藏」「最近访问」是同级的快捷视图。
- **紧凑网格卡片**：宽屏 4 列、中等屏 3 列、平板 2 列、手机 1 列；卡片包含图标、名称、用途说明、标签与使用次数。
- **三种排序**：使用次数（默认，从高到低）、最近使用、名称（中文按拼音）。切换分类后沿用当前排序。
- **真实跳转**：点击卡片在新标签页打开对应网站。
- **访问统计**：打开网站后自动 +1 次使用次数，并记录最近使用时间；「最近访问」按时间倒序展示最近 5 条。
- **收藏**：卡片右上角星标可收藏 / 取消收藏，「我的收藏」查看收藏列表，空状态有提示。
- **网站管理（V0.1.1）**：
  - 标题区「添加网站」按钮打开表单弹窗，必填名称、网址、所属分类，可选用途说明与标签；新增网站初始使用次数为 0，立即参与筛选与排序。
  - 卡片右上角「⋯」菜单提供编辑与删除；编辑复用同一表单并自动回填。
  - 删除前弹出二次确认，删除后同步清除该网站的收藏与访问记录，不残留无效数据。
- **本地持久化**：整个网站列表（含新增、编辑、删除、次数与收藏状态）保存在 `localStorage`，刷新或重新打开页面后原样恢复。
- **响应式与无障碍**：无横向溢出，键盘可遍历导航、排序与卡片，焦点样式清晰，弹窗支持 `Esc` 关闭，支持 `prefers-reduced-motion`。

## 本地预览

直接双击 `index.html` 也能打开；若浏览器对本地文件有限制，用任意静态服务器：

```bash
# 任选一种
npx serve .
python -m http.server 8123
```

然后访问终端里给出的地址（例如 `http://localhost:8123/`）。

## 部署到 GitHub Pages

1. 新建仓库并推送本目录内容到 `main` 分支：

   ```bash
   git init
   git add .
   git commit -m "StudyHub V0.1.1"
   git branch -M main
   git remote add origin https://github.com/<用户名>/<仓库名>.git
   git push -u origin main
   ```

2. 仓库 **Settings → Pages**：Source 选择 `Deploy from a branch`，Branch 选 `main` + `/ (root)`，保存。
3. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

所有资源都使用相对路径，仓库名随意，无需额外配置。数据只存在各自浏览器里，部署后新增的网站不会自动出现在其他设备上。

## 数据结构

`js/data.js` 通过全局变量 `window.STUDYHUB_DATA` 暴露初始数据（普通 `<script>` 加载，不使用 ES modules / fetch，因此在本地 HTTP 服务与 GitHub Pages 上表现一致）：

```js
{
  meta: { version: '0.1.1', storageKey: 'studyhub:v1' },
  categories: [{ id, name, icon, color }],
  sites: [{
    id, name, desc, url, category,
    icon, color, tags: [],
    initialVisits,       // 首次使用时的初始次数
    seededHoursAgo       // 首次使用时的初始「最近访问」时间
  }]
}
```

### 运行时存储

首次访问时，`app.js` 把 `data.js` 的网站转换成统一的运行时结构写入 `localStorage` 的 `studyhub:v1` 键；之后所有增删改都直接修改这份数据：

```js
{
  version: 2,
  updatedAt: <时间戳>,
  sites: [{
    id, name, desc, url, category,
    icon, color, tags: [],
    visits,      // 使用次数
    lastUsed,    // 最近使用时间戳，0 表示从未访问
    favorite     // 是否收藏
  }]
}
```

预置网站与用户新增网站使用完全相同的结构，卡片渲染、排序、筛选、收藏和最近访问都只读这一份列表。若检测到旧的 V0.1 数据（`version: 1` 的「基础数据 + 记录分离」结构），会自动合并迁移为 V2。

### 关于 `data.js`

`data.js` 现在只作为**首次访问的种子数据**。一旦浏览器里已经存有 `studyhub:v1`，再修改 `data.js` 不会影响已有数据；需要重置时清除该站点的 `localStorage`（或浏览器开发者工具里删除该键）后刷新即可重新播种。

## 校验规则

| 字段 | 规则 |
| --- | --- |
| 网站名称 | 必填，最多 30 字 |
| 网站网址 | 必填，自动补全 `https://`；仅允许 http / https；域名需含点；去掉 `#` 片段后保存 |
| 重复网址 | 忽略 `www.`、末尾 `/` 与大小写差异后判重，重复时拒绝保存 |
| 所属分类 | 必选，限五个分类之一；新增或改分类时自动套用该分类的图标与配色 |
| 用途说明 | 可选，最多 60 字 |
| 标签 | 可选，支持 `,` `，` `、` `;` `；` 与空格分隔，最多 3 个，每个最多 8 字，自动去重 |

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无第三方依赖、无外部字体与 CDN 请求。
- 普通 `<script>` 顺序加载，`data.js` 先于 `app.js`。
- 图标为内联 SVG `<symbol>` + `<use>`，随文字颜色变化，不产生额外请求。
- 表单使用原生 `<dialog>`，自带焦点管理与 `Esc` 关闭；关闭时同步解除页面滚动锁。
- 数据渲染对文本做 HTML 转义、对 URL 做协议校验，避免引入不可信内容；用户输入永远不会作为 HTML 注入。
